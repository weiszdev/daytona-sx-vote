How to Install

  1. Install Tampermonkey (Chrome, Firefox, Edge) or Violentmonkey.
  2. Click Install MotoMic Userscript — Tampermonkey will prompt you to confirm.
  3. Open live.supercrosslive.com during a race.
  4. The MotoMic board replaces the stock table automatically.

For OBS / streaming: add a Browser Source pointed at live.supercrosslive.com with Tampermonkey installed in the browser profile. The board is sized for 1920×1080.

Config Options

Edit the CONFIG object near the top of the userscript:

OptionDefaultDescription
layout"two-column"Board style. Also supports "compact-table".
rowMode"all-riders"Show all riders, or "fit-screen" to fit viewport.
showVideoSlottrueShow/hide the center 16:9 video placeholder.
showColumnspos, #, name, bike, last, best, gapWhich timing columns to display.
maxRiders"auto"Cap rider count, or "auto" for all.
brandName"MotoMic"Header brand text.

Minimal Ticker Mode

For a cleaner stream overlay with larger rider names:

showColumns: ["pos", "number", "name", "bike", "best"]

Fox Raceway Schedule

The userscript includes the full Fox Raceway Saturday schedule. Countdowns update automatically. To change events, edit the EVENT_SCHEDULE array in the userscript.
